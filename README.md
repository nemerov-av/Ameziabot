# 🚀 AmneziaWG Telegram VPN Bot

Telegram-бот для автоматизации выдачи и управления ключами доступа к VPN-серверу **AmneziaWG**. Бот обрабатывает заявки пользователей, генерирует конфигурационные файлы `.conf` и нативные ссылки `vpn://`, а также предоставляет полноценную административную панель для управления сервером и лимитами.

---

## 📌 Основные возможности

* **Запрос и выдача ключей:** Регистрация пользователей с подтверждением номера телефона через Telegram.
* **Гибкая модерация:** 
  * Автоматическая выдача ключей для номеров из **Белого списка**.
  * Ручное одобрение/отклонение новых заявок администратором.
  * Установка индивидуальных лимитов на количество ключей для одного номера.
* **Генерация конфигураций:** Создание готовых `.conf` файлов и универсальных `vpn://` ключей для приложения AmneziaVPN.
* **Админ-панель (`/admin`):**
  * Просмотр статистики трафика пользователей в реальном времени.
  * Управление Белым списком номеров.
  * Просмотр профилей пользователей, выгрузка и отзыв (удаление) ключей.
* **Поддержка отмены:** Команда `/cancel` сбрасывает текущий шаг ввода на любой стадии.
* **Интеграция с донатами:** Сообщение с реквизитами поддержки сервера после успешной выдачи ключа.

---

## 🛠 Технологический стек

* **Python 3.10** (`pyTelegramBotAPI`, `paramiko`)
* **SQLite3** (хранение пользователей, заявок, белого списка и лимитов)
* **Docker & Docker Compose** (контейнеризация бота)
* **Paramiko SSH** (взаимодействие с Docker-контейнером AmneziaWG на сервере)

---

## 📋 Предварительные требования

1. **Сервер с AmneziaWG:** Установленный контейнер AmneziaWG (по умолчанию `amnezia-awg2`).
2. **Docker и Docker Compose** на машине, где запускается бот.
3. **Telegram Bot Token:** Полученный через [@BotFather](https://t.me/BotFather).
4. **SSH-ключ:** Закрытый ключ (`id_ed25519`) для подключения бота к серверу VPN по SSH.

---

## ⚙️ Настройка проекта

Перед запуском убедитесь, что в коде бота (`main.py`) указаны корректные параметры:

* `BOT_TOKEN` — токен вашего Telegram-бота.
* `ADMIN_IDS` — список ID администраторов Telegram (например, `[111439111]`).
* `SSH_HOST`, `SSH_PORT`, `SSH_USER`, `SSH_KEY_PATH` — параметры подключения к VPN-серверу.
* `CONTAINER_NAME`, `INTERFACE_NAME`, `SERVER_PUBKEY`, `SERVER_ENDPOINT` — параметры AmneziaWG.

> **Примечание:** Если вы используете файл `main_2.py`, переименуйте его в `main.py` или измените последнюю строчку в `Dockerfile` на `CMD ["python", "main_2.py"]`.

## 🐳 Установка и запуск в Docker

### 1. Структура проекта

Убедитесь, что файлы расположены следующим образом:

```text
.
├── Dockerfile
├── docker-compose.yml
├── requirements.txt
├── .env             # Переименованный и заполненый env
├── main.py
├── id_ed25519       # Приватный SSH-ключ для доступа к VPN-серверу
└── bot_data/        # Директория создается автоматически для vpn_users.db
2. Сборка и запуск контейнера
Выполните команду в корневой директории проекта:
  docker compose up -d --build

3. Полезные команды Docker
Просмотр логов работы бота:
  docker logs -f amnezia_telegram_bot
Остановка бота:
  docker compose down
Перезапуск бота:
  docker compose restart


📱 Команды бота
Команда          Описание
/start            Главный экран и кнопка начала регистрации
/register         Быстрый запуск процесса регистрации
/cancel           Отмена текущего действия и возврат на главный экран
/admin            Панель администратора (доступна только ID из ADMIN_IDS)
